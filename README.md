# ScreenAid Studio

가벼운 Windows 전용 화면 보조 도구입니다. 클릭 표시, 화면 그리기, 영역 캡처, 고정 화면, 실시간 화면을 제공하며 기본 원칙은 낮은 CPU 사용량과 입력 방해 방지입니다.

## 선택한 라이브러리

- `PySide6`: 투명 오버레이, 트레이, 설정창, 도구 모음을 안정적으로 구성합니다.
- `ctypes`: DPI, click-through 창 스타일, low-level mouse hook, BitBlt 같은 Windows API를 추가 의존성 없이 호출합니다.
- `configparser`: INI 설정을 표준 라이브러리로 저장하고 읽습니다.
- `mss`, `Pillow`: 기본 경로에서는 사용하지 않으며, 향후 고급 캡처나 이미지 처리 단계에서만 검토합니다.

## 깨끗한 Python 환경에서 설치

필수 실행 라이브러리는 [requirements.txt](D:/codex/ScreenAssistant/requirements.txt)에 있습니다. 현재 실제 실행에 필요한 외부 패키지는 `PySide6` 하나이며, Windows API 호출과 INI 설정 처리는 Python 표준 라이브러리를 사용합니다.

```powershell
cd ScreenAssistant
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```

의존성 구분은 다음 파일에서 확인할 수 있습니다.

| 위치 | 용도 |
| --- | --- |
| `requirements.txt` | 일반 실행에 필요한 최소 패키지 |
| `pyproject.toml`의 `dependencies` | 패키징 기준 실행 의존성 |
| `pyproject.toml`의 `optional-dependencies.capture` | 향후 선택 캡처/이미지 처리 후보 |
| `pyproject.toml`의 `optional-dependencies.dev` | 테스트, 린트, 타입 검사 같은 개발용 도구 |

현재 구분:

| 구분 | 패키지 |
| --- | --- |
| 실행 필수 | `PySide6>=6.7` |
| 선택 후보 | `mss`, `Pillow` |
| 개발용 | `pytest`, `pytest-cov`, `ruff`, `mypy` |

## 실행

```powershell
cd ScreenAssistant
python -m pip install -r requirements.txt
python main.py
```

기본 사용자 설정은 실행 폴더의 `user_data\` 아래에 저장되는 휴대용 모드로 동작합니다. 설정창의 `설정 저장 위치`에서 `휴대용 모드(프로그램 폴더)` 또는 `사용자 AppData 폴더`를 선택할 수 있으며, 저장 위치 변경은 다음 실행부터 적용됩니다. 기존 호환성을 위해 실행 폴더에 `portable.flag` 파일이 있으면 항상 휴대용 모드를 우선 사용합니다. 프로그램은 별도 로그 파일을 생성하지 않습니다.

트레이에는 화면, 포인터, 펜을 조합한 ScreenAid Studio 아이콘이 표시됩니다. 일시중지, 그리기, 클릭 효과 숨김 상태에서는 작은 배지가 아이콘에 표시되고, 마우스를 올리면 `ScreenAid Studio(상태값)` 형태의 툴팁이 보입니다. Windows Explorer가 재시작되어 트레이 아이콘이 사라져도 `TaskbarCreated` 메시지를 감지해 다시 등록합니다. 트레이 아이콘을 우클릭하면 메뉴가 열리고, 더블클릭하면 설정창이 열립니다.

## 설정창

설정창은 일반, 오버레이, 클릭, 캡처, 그리기, 고정 화면, 실시간, 단축키, 명령 모드, 영역 선택 탭으로 구성됩니다. 항목이 많은 탭은 스크롤로 이동할 수 있으며, `저장`은 창을 닫지 않고 INI 설정과 실행 중 상태를 갱신하고 `저장 후 닫기`는 저장한 뒤 창을 닫습니다. 선택 메뉴는 화면에는 현재 언어로 표시하고, 설정 파일에는 호환 가능한 내부 키를 저장합니다.

단축키 탭에서는 명령 모드 진입 전역 단축키와 클릭 효과 임시 표시/숨김 전역 단축키를 변경할 수 있습니다. 저장하면 실행 중인 단축키 등록을 해제한 뒤 새 조합으로 다시 등록합니다.

명령 모드는 기본 `Ctrl+Alt+A`로 들어갑니다. 명령 모드에 들어간 뒤 `D`, `R`, `K`, `G`, `S`, `Space` 같은 한 글자 키로 기능을 실행하고, `Esc`로 취소합니다. 힌트 창은 시스템, 그리기, 캡처, 창, 설정 그룹으로 나눠 표시합니다. `Ctrl+Alt+E`는 설정값을 바꾸지 않고 실행 중 클릭 효과 표시만 임시로 켜거나 끕니다. 전역 단축키와 내부 키 모두 설정창에서 바꿀 수 있습니다. 명령 모드 사용 여부는 끄면 단축키 입구가 사라질 수 있으므로 설정창에 체크박스로 노출하지 않고 항상 켜진 상태로 저장합니다.

설정창의 `Restore Defaults` 버튼을 누르면 확인 후 전체 설정을 기본값으로 되돌립니다.

`Import Settings`와 `Export Settings`로 현재 설정을 INI 파일로 백업하거나 다른 PC의 설정 파일을 가져올 수 있습니다. 가져오기 전에는 확인 창을 표시하고, 기존 설정은 자동 백업됩니다.

아직 확장 대상으로 남아 있는 설정 기능은 고급 미리보기입니다.

## 언어

기본으로 한국어와 영어를 지원합니다. `config/settings.ini` 또는 설정창의 `언어` 항목에서 선택할 수 있으며, 변경 후 프로그램을 다시 시작하면 메뉴, 설정창, 툴팁, 알림에 적용됩니다.

다른 언어를 추가하려면 `locales/` 폴더에 `ja.ini`, `zh.ini` 같은 INI 파일을 만들고 `[meta] name`, `[strings]` 번역 키를 채우면 됩니다. 없는 번역 키는 영어 또는 키 이름으로 대체되며 프로그램 실행을 막지 않습니다.

## 명령 모드 키

- `Ctrl+Alt+A`: 명령 모드 열기
- `Ctrl+Alt+E`: 클릭 효과 임시 표시/숨김
- `O`: 오버레이 표시 전환
- `E`: 클릭 효과 임시 표시/숨김
- `D`: 그리기 모드 토글
- `P`: 입력 통과 모드
- `C`: 그리기 전체 지우기
- `Z`: 그리기 실행 취소
- `Y`: 그리기 다시 실행
- `R`: 영역 캡처
- `L`: 마지막 영역 다시 캡처
- `M`: 현재 모니터 캡처
- `V`: 전체 화면 캡처
- `W`: 활성 창 캡처
- `K`: 영역 선택 후 고정 화면 열기
- `B`: 마지막 캡처 고정
- `G`: 실시간 영역 선택
- `X`: 실시간 화면 모두 닫기
- `S`: 설정창 열기
- `Space`: 전체 일시중지 또는 재개
- `Esc`: 명령 모드 취소

## 클릭 표시

설정창의 클릭 탭에서 클릭 표시 전체 사용 여부를 켜거나 끌 수 있고, 마우스 클릭 표시 박스 안에서 왼쪽 클릭, 오른쪽 클릭, 양쪽 동시 클릭, 휠 클릭, 휠 드래그(돌리기), 더블클릭 표시 여부를 각각 선택할 수 있습니다. 색상, 크기, 유지 시간, 사라짐 시간도 설정할 수 있습니다.

클릭 표시 이미지는 기본적으로 `resources/click_indicators/`의 PNG 파일을 사용합니다. 휠 회전 이미지는 마우스 내부에 방향 화살표를 표시합니다. 이미지가 없거나 읽을 수 없으면 벡터 기반 표시로 자동 대체됩니다. 트레이 아이콘은 화면 보조 기능 전체를 나타내는 `resources/tray_icon.ico`를 우선 사용하고, 파일이 없으면 코드에서 그린 기본 아이콘으로 대체됩니다.

## 화면 그리기

명령 모드에서 `D`를 누르면 그리기 모드로 전환되고 펜 모양 커서가 표시됩니다. 도구 모음에서 펜, 형광펜, 직선, 화살표, 사각형, 원/타원, 도장, 지우개를 선택할 수 있습니다. 지우개는 설정의 지우개 모드에 따라 개체 전체 삭제 또는 지나간 경로만 지우는 픽셀 지우개로 동작합니다. 색상, 굵기, 선 모양은 아이콘 버튼을 눌러 팝업에서 고릅니다.

도장 도구는 별 아이콘 하나로 표시되며 팝업에서 별, 하트, 체크, X, 느낌표를 선택합니다. 별은 반듯한 도형보다 사람이 손으로 그린 듯한 외곽선 느낌으로 표시됩니다. 클릭하면 기본 크기로 찍히고, 드래그하면 크기를 조절해서 찍을 수 있습니다.

설정창의 그리기 탭에서 `도구 모음 버튼 크기`를 22~48px 범위로 조절할 수 있습니다. `저장`을 누르면 전체 화면 그리기 도구 모음과 이미 열려 있는 고정 화면 주석 도구 모음에 바로 반영됩니다.

전체 화면 그리기 도구 모음은 마지막으로 드래그한 위치를 기억해 다음 실행 또는 다음 그리기 모드 진입 때 복원합니다. 저장된 위치가 현재 모니터 밖이면 사용 가능한 화면 안으로 자동 보정됩니다. 고정 화면 주석 도구 모음은 각 창에서 사용자가 옮긴 위치를 유지하며, 창 크기 변경 때 임의로 원위치로 돌아가지 않습니다.

그리기 모드에서는 실제 마우스 포인터는 정상적으로 움직이지만, 그리기 입력이 아래 프로그램으로 전달되지 않도록 막습니다. 도구 모음을 클릭하거나 드래그할 때는 화면에 선이 그려지지 않습니다.

## 캡처

영역 캡처는 선택 오버레이에서 드래그한 사각형만 캡처합니다. 기본 동작은 클립보드 복사이며, 설정창의 캡처 탭에서 자동 저장, 저장 형식, 파일명 패턴, 커서 포함 여부 등을 바꿀 수 있습니다.

정적 캡처는 Windows `BitBlt`를 우선 사용합니다. 실행 환경에서 Desktop DC 캡처가 실패하면 Qt screen grab으로 한 번 대체합니다.

## 고정 화면과 실시간 화면

`Pin Region` 또는 명령 모드의 `K`로 영역을 선택하면 고정 화면 창이 열립니다. 마우스 휠로 확대/축소하고, 드래그로 창을 이동하며, 우클릭 메뉴에서 입력 통과, 주석 모드, 복사, 저장, 닫기를 사용할 수 있습니다. 창이 선택된 상태에서 `Esc`를 누르면 닫힙니다.

`Start Live Region` 또는 명령 모드의 `G`로 영역을 선택하면 기본 10FPS 실시간 화면 창이 열립니다. 실시간 화면도 테두리 없이 표시되며, 마우스 휠로 확대/축소하고 드래그로 이동합니다. 캡처는 별도 Worker에서 처리하고 대기 요청은 최신 1개만 유지하여 지연 프레임이 쌓이지 않게 합니다. `Stop Live Views`로 모든 실시간 화면을 닫습니다.

## 전체 일시중지

트레이의 `Pause All` 또는 명령 모드의 `Space`를 누르면 전체 일시중지 상태로 전환됩니다. 이 상태에서는 클릭 표시와 화면 그리기 입력이 멈추고, 새 캡처/고정 화면/실시간 화면 시작 명령은 실행되지 않습니다. 다시 같은 메뉴나 키를 실행하면 재개됩니다.

## 설정창 구조

설정창 본체는 `ui/settings_dialog.py`에서 창 조립, 버튼 연결, 공통 헬퍼만 담당합니다. 탭 UI는 `ui/settings_tabs.py`, 설정값 읽기와 저장은 `ui/settings_values.py`, 단축키/명령 모드/영역 선택 같은 공통 섹션은 `ui/settings_sections.py`에 분리되어 있습니다. 새 설정을 추가할 때는 가능하면 해당 탭 또는 값 처리 파일에만 작게 추가합니다.

## 다중 모니터 좌표

클릭 표시와 전체 화면 그리기는 Windows 마우스 Hook의 물리 좌표를 기준으로 표시합니다. 혼합 DPI 환경에서 물리 좌표와 논리 좌표를 섞지 않도록 오버레이 가상 화면과 클릭/그리기 좌표를 같은 물리 좌표계로 통일합니다.

## PyInstaller 폴더 배포 빌드

배포 빌드는 PyInstaller 기반 폴더 배포를 기본으로 합니다.

```powershell
cd ScreenAssistant
.\build_exe.ps1
```

빌드 결과는 `dist\ScreenAidStudio\ScreenAidStudio.exe`입니다. 콘솔 창은 숨김, 관리자 권한 요청 없음, 아이콘은 `resources\tray_icon.ico`, 파일 버전은 `0.1.0.0`, 회사/제작자 이름은 `JunoSsam`으로 설정됩니다.

배포 폴더에는 `portable.flag`, `config`, `locales`, `resources`, `docs`, `LICENSE`가 포함됩니다. 사용자 설명서는 트레이 메뉴의 `사용설명서 열기` 또는 설정창의 `저작권/설명` 탭에서 열 수 있습니다.

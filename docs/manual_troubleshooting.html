문제 해결

자주 겪을 수 있는 상황과 해결 방법입니다.

처음빠른 시작기능과 단축키속성 설정

PySide6.QtCore 또는 libshiboken 오류

ImportError: libshiboken: could not import module 'PySide6.QtCore' 오류가 보이면 배포 폴더의 런타임 DLL을 찾지 못한 상태입니다. 최신 배포판에서는 실행 초기에 PySide6와 shiboken DLL 경로를 자동 등록합니다. 그래도 문제가 나면 ScreenAidStudio.exe만 복사하지 말고 ScreenAidStudio 폴더 전체를 다시 압축 해제하거나 이동하세요.

증상확인할 것
트레이 아이콘이 보이지 않음숨겨진 아이콘 영역을 열어 확인합니다. Windows Explorer가 재시작되면 아이콘이 자동 복구될 수 있습니다.
명령 모드가 열리지 않음다른 프로그램이 같은 전역 단축키를 사용 중일 수 있습니다. 설정창의 단축키 탭에서 다른 키로 바꿉니다.
클릭 표시가 보이지 않음Ctrl + Alt + E로 임시 숨김 상태가 아닌지 확인합니다. 설정창의 클릭 탭에서 전체 사용 여부와 클릭 종류별 체크 상태를 확인합니다.
그리기 중 아래 프로그램이 클릭되지 않음정상 동작입니다. 그리기 모드에서는 아래 프로그램 입력을 막습니다. 명령 모드에서 P를 눌러 입력 통과로 돌아갑니다.
고정 화면 또는 실시간 화면이 Esc로 닫히지 않음창의 입력 통과가 켜져 있으면 키 입력을 받지 못합니다. 우클릭 메뉴에서 입력 통과를 끈 뒤 다시 시도합니다.
실시간 화면이 느림우클릭 메뉴에서 FPS를 낮추거나 선택 영역을 작게 잡습니다.
캡처가 원하는 영역과 다름모니터 배율을 바꾼 직후라면 프로그램을 다시 실행해 보세요. 여러 모니터를 사용할 때는 선택 영역이 실제 표시 위치와 맞는지 확인합니다.

개인정보

ScreenAid Studio는 별도 로그 파일을 생성하지 않습니다. 화면 이미지는 사용자가 캡처, 복사, 저장을 실행한 경우에만 처리됩니다.

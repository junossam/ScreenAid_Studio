문제 해결

자주 만나는 증상과 확인 방법입니다.

처음빠른 시작기능과 단축키속성 설정

실행 문제

증상확인할 것
ImportError: libshiboken 또는 PySide6.QtCore 오류ScreenAidStudio.exe만 따로 옮기지 않았는지 확인합니다. internal 폴더가 포함된 배포 폴더 전체를 다시 복사하세요.
아무 창도 뜨지 않는 것처럼 보임ScreenAid Studio는 기본적으로 트레이에서 실행됩니다. 작업 표시줄 오른쪽의 숨겨진 아이콘 영역을 확인하세요.
트레이 아이콘이 보이지 않음숨겨진 아이콘 영역을 열어보거나 프로그램을 다시 실행합니다. 이미 실행 중이면 중복 실행 방지 때문에 새 창이 뜨지 않을 수 있습니다.

단축키 문제

증상해결 방법
명령 모드가 열리지 않음다른 프로그램이 같은 전역 단축키를 사용 중일 수 있습니다. 속성의 단축키 탭에서 다른 조합으로 바꿔보세요.
명령 모드에서 특정 키가 동작하지 않음속성의 명령 모드 탭에서 같은 키가 여러 명령에 중복되어 있지 않은지 확인합니다.
Ctrl + Alt + A 반응이 느림최신 버전은 명령 모드 키보드 훅을 미리 준비하도록 개선되었습니다. 오래된 배포판이면 최신 버전을 내려받아 사용하세요.

클릭 표시 문제

증상확인할 것
클릭 표시가 보이지 않음Ctrl + Alt + E로 임시 숨김 상태가 아닌지 확인합니다. 속성의 클릭 탭에서 클릭 표시 사용과 클릭 종류별 체크 상태도 확인하세요.
클릭 이미지가 보이지 않음배포 폴더의 resources/click_indicators 폴더가 함께 있는지 확인합니다.
클릭 위치가 맞지 않음프로그램을 최신 버전으로 업데이트하세요. 모니터 배율을 바꾼 직후라면 프로그램을 다시 실행해 보세요.

그리기 문제

증상확인할 것
그리기 중 아래 프로그램이 클릭되지 않음정상 동작입니다. 그리기 모드에서는 아래 프로그램 조작을 막고 화면 위에 그립니다. 아래 프로그램을 조작하려면 명령 모드에서 P를 눌러 입력 통과를 켜세요.
도구 모음이 화면을 가림도구 모음을 드래그해서 원하는 위치로 옮길 수 있습니다. 버튼 크기는 속성의 그리기 탭에서 조절합니다.
지우개가 원하는 방식으로 동작하지 않음속성의 그리기 탭에서 개체 지우개와 픽셀 지우개 중 원하는 방식을 선택하세요.

캡처와 창 문제

증상확인할 것
고정 화면이나 실시간 화면이 Esc로 닫히지 않음입력 통과가 켜져 있으면 창이 키 입력을 받지 못할 수 있습니다. 우클릭 메뉴에서 입력 통과를 끄고 다시 시도하세요.
실시간 영역 화면이 느림우클릭 메뉴에서 FPS를 낮추거나 선택 영역을 작게 잡습니다. 큰 영역을 높은 FPS로 갱신하면 CPU 사용량이 늘어납니다.
캡처 후 오래 버벅임큰 영역, 전체 가상 화면, 고해상도 모니터 캡처는 시간이 걸릴 수 있습니다. 필요한 영역만 작게 선택하면 부담이 줄어듭니다.

확대 문제

증상확인할 것
현재 화면 확대가 열리지 않음속성의 확대 탭에서 전체 화면 확대 사용이 켜져 있는지 확인합니다.
확대 중 그리기 주석이 남지 않음속성의 확대 탭에서 확대 종료 시 주석 남기기 옵션을 켰는지 확인합니다.

알림 문제

증상확인할 것
알림이 너무 많이 뜸속성의 알림 탭에서 전체 알림을 끄거나 필요한 알림만 켜세요.
알림이 보이지 않음속성의 알림 탭과 Windows 알림 설정을 확인하세요.
알림 제목이 이상하게 표시됨최신 버전에서는 알림 제목이 ScreenAid Studio로 표시되도록 조정되어 있습니다. 실행 중인 프로그램을 완전히 종료한 뒤 다시 실행하세요.

개발자 진단 로그

일반 사용 모드에서는 로그 파일을 만들지 않습니다. 다른 PC에서 실행 원인을 파악해야 할 때만 실행 폴더에 developer.log 파일을 만들고 다시 실행하세요. 해당 파일이 있으면 개발자 진단 모드로 동작하며 시작 과정과 예외 정보를 그 파일에 기록합니다.

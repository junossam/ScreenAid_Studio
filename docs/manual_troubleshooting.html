문제 해결

자주 겪을 수 있는 상황과 확인 방법입니다.

처음빠른 시작기능과 단축키속성 설정

실행 오류

증상확인할 것
ImportError: libshiboken 또는 PySide6.QtCore 오류exe만 따로 옮기지 않았는지 확인합니다. _internal 폴더가 포함된 배포 폴더 전체를 다시 복사하세요.
아무 창도 뜨지 않는 것처럼 보임트레이 영역의 숨겨진 아이콘을 확인합니다. ScreenAid Studio는 기본적으로 트레이에서 실행됩니다.
트레이 아이콘이 보이지 않음Windows 작업 표시줄의 숨겨진 아이콘 영역을 열어 봅니다. 그래도 없으면 프로그램을 다시 실행합니다.

단축키 문제

증상해결 방법
명령 모드가 열리지 않음다른 프로그램이 같은 전역 단축키를 사용 중일 수 있습니다. 설정창의 단축키 탭에서 다른 조합으로 바꿉니다.
명령 모드에서 원하는 키가 동작하지 않음설정창의 명령 모드 탭에서 같은 키가 여러 명령에 중복되어 있지 않은지 확인합니다.
Esc로 고정 화면이나 실시간 화면이 닫히지 않음창의 입력 통과가 켜져 있으면 키 입력을 받지 못할 수 있습니다. 우클릭 메뉴에서 입력 통과를 끈 뒤 다시 시도합니다.

클릭 표시 문제

증상확인할 것
클릭 표시가 보이지 않음Ctrl + Alt + E로 임시 숨김 상태가 아닌지 확인합니다. 설정창의 클릭 탭에서 클릭 표시 사용과 클릭 종류별 체크 상태도 확인합니다.
클릭 이미지가 보이지 않음배포 폴더의 resources/click_indicators 아래에 이미지 파일이 있는지 확인합니다. 폴더 전체를 다시 복사하면 대부분 해결됩니다.
원하는 클릭 종류만 표시하고 싶음설정창의 클릭 탭에서 왼쪽, 오른쪽, 양쪽, 휠 클릭, 휠 드래그, 더블클릭을 각각 켜거나 끕니다.

그리기 문제

증상확인할 것
그리기 중 아래 프로그램이 클릭되지 않음정상 동작입니다. 그리기 모드에서는 실수로 아래 프로그램이 움직이지 않도록 입력을 막습니다. 아래 프로그램을 조작하려면 명령 모드에서 P를 누릅니다.
도구 모음이 화면을 가림도구 모음을 드래그해서 옮깁니다. 크기가 부담스러우면 설정창의 그리기 > 도구 모음 버튼 크기를 줄입니다.
지우개가 원하는 방식으로 동작하지 않음설정창에서 개체 지우개와 픽셀 지우개 중 원하는 방식을 선택합니다. 개체 지우개는 도형 전체를, 픽셀 지우개는 지나간 부분만 지웁니다.

캡처와 실시간 화면 문제

증상확인할 것
캡처 위치가 원하는 영역과 다름모니터 배율을 바꾼 직후라면 프로그램을 다시 실행해 봅니다. 여러 모니터를 사용할 때는 실제 선택 영역과 표시 위치가 맞는지 확인합니다.
실시간 화면이 느림우클릭 메뉴에서 FPS를 낮추거나 선택 영역을 작게 잡습니다. 큰 영역을 높은 FPS로 갱신하면 CPU 사용량이 늘어납니다.
고정 화면이 아래 프로그램 클릭을 막음우클릭 메뉴에서 입력 통과를 켭니다. 다시 창을 조작하려면 입력 통과를 끕니다.

개인정보

ScreenAid Studio는 별도 로그 파일을 생성하지 않습니다. 화면 이미지는 사용자가 캡처, 복사, 저장을 실행한 경우에만 처리됩니다.

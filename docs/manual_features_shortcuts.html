명령 모드

Ctrl + Alt + A를 누르면 명령 모드가 열립니다. 화면 아래쪽에 시스템, 그리기, 캡처, 창, 설정 그룹으로 나뉜 힌트가 표시됩니다. 원하는 키를 누르면 바로 실행되고, Esc를 누르면 취소됩니다.

클릭 표시

마우스를 클릭하면 포인터 오른쪽 아래에 클릭 종류를 나타내는 이미지가 표시됩니다. 표시할 클릭 종류는 설정창에서 각각 켜거나 끌 수 있습니다.

화면 그리기

명령 모드에서 D를 누르면 그리기 모드가 켜지고 펜 모양 커서와 도구 모음이 표시됩니다. 펜, 형광펜, 직선, 화살표, 사각형, 원, 도장, 지우개를 사용할 수 있습니다.

그리기 모드에서는 아래 프로그램이 함께 클릭되지 않습니다. 일반 조작으로 돌아가려면 명령 모드에서 P를 누릅니다.

고정 화면

K로 영역을 선택하면 선택한 화면이 테두리 없는 별도 창으로 뜹니다. 마우스 휠로 확대/축소하고, 드래그로 창을 이동합니다. 우클릭 메뉴에서 주석 모드, 입력 통과, 복사, 저장, 닫기를 사용할 수 있습니다.

실시간 화면

G로 영역을 선택하면 해당 영역을 계속 갱신하는 실시간 창이 열립니다. 실시간 창도 휠 확대/축소와 드래그 이동을 지원합니다. 모든 실시간 창을 닫으려면 명령 모드에서 X를 누릅니다.

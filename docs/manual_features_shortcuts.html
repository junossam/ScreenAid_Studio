수업, 발표, 시연 중 자주 쓰는 기능과 조작 방법입니다.

처음빠른 시작속성 설정문제 해결

명령 모드

Ctrl + Alt + A를 누르면 명령 모드가 열립니다. 화면 아래쪽에 실행할 수 있는 명령이 그룹별로 표시됩니다. 명령 모드가 열린 상태에서 알파벳 한 글자만 누르면 해당 기능이 실행되고, Esc를 누르면 아무 작업 없이 닫힙니다.

예: Ctrl + Alt + A를 누른 뒤 D를 누르면 그리기 모드가 켜집니다. 다시 같은 방식으로 D를 누르면 그리기 모드가 꺼집니다.

그룹키동작언제 쓰나요?
시스템O오버레이 표시 전환화면 보조 표시 전체를 잠시 숨기거나 다시 보일 때 사용합니다.
시스템E클릭 효과 임시 표시/숨김설정값은 그대로 두고 지금 당장 클릭 표시만 잠깐 끄거나 켭니다.
시스템Space전체 일시중지/재개수업 중 프로그램 기능 전체를 잠시 멈추고 싶을 때 사용합니다.
그리기D그리기 모드 토글화면 위에 펜, 도형, 도장, 지우개를 사용할 때 켭니다.
그리기P입력 통과 모드그리기는 유지한 채 아래 프로그램을 클릭하고 싶을 때 사용합니다.
그리기C그리기 전체 지우기화면에 그린 내용을 한 번에 지웁니다.
그리기Z / Y실행 취소 / 다시 실행방금 그린 선이나 도형을 되돌리거나 다시 살립니다.
캡처R영역 캡처드래그로 선택한 영역을 이미지로 저장하거나 클립보드에 복사합니다.
캡처L마지막 영역 다시 캡처같은 영역을 반복해서 캡처할 때 사용합니다.
캡처M현재 모니터 캡처마우스가 있는 모니터 전체를 캡처합니다.
캡처V전체 화면 캡처연결된 모든 모니터의 가상 화면 전체를 캡처합니다.
캡처W활성 창 캡처현재 선택된 프로그램 창만 캡처합니다.
창K영역 선택 후 고정 화면 열기선택한 영역을 테두리 없는 별도 창으로 띄워 계속 보여줍니다.
창B마지막 캡처 고정방금 캡처한 이미지를 다시 별도 창으로 띄웁니다.
창G실시간 영역 선택선택한 화면 영역을 계속 갱신되는 작은 창으로 보여줍니다.
창X실시간 화면 모두 닫기열려 있는 실시간 화면 창을 한 번에 닫습니다.
설정S설정창 열기언어, 클릭 표시, 단축키, 그리기 옵션을 바꿉니다.

마우스 클릭 표시

마우스를 클릭하면 포인터 오른쪽 아래에 클릭 종류를 나타내는 이미지가 표시됩니다. 왼쪽 클릭, 오른쪽 클릭, 양쪽 동시 클릭, 휠 클릭, 휠 드래그, 더블클릭을 각각 표시할 수 있습니다.

표시 종류설명
왼쪽 클릭 표시일반 선택, 버튼 클릭, 슬라이드 넘김 같은 가장 기본적인 클릭을 보여줍니다.
오른쪽 클릭 표시컨텍스트 메뉴를 열 때 청중이 오른쪽 클릭임을 알아볼 수 있게 합니다.
양쪽 동시 클릭 표시왼쪽과 오른쪽 버튼을 거의 동시에 누른 경우를 별도로 표시합니다.
휠 클릭 표시마우스 휠 버튼을 누르는 동작을 표시합니다.
휠 드래그(돌리기) 표시휠을 위, 아래, 좌, 우로 움직이는 동작을 화살표로 표시합니다.
더블클릭 표시짧은 시간 안에 왼쪽 클릭을 두 번 누른 경우를 표시합니다.

그리기 모드 기본 사용

그리기 모드가 켜지면 펜 모양 커서와 작은 도구 모음이 나타납니다. 이 상태에서는 아래 프로그램으로 클릭이 통과하지 않으므로 PowerPoint, Chrome, 한글, Excel 같은 프로그램이 실수로 눌리지 않습니다. 도구 모음 자체를 클릭하거나 드래그할 때는 화면에 선이 그려지지 않습니다.

도구 모음은 드래그해서 원하는 곳으로 옮길 수 있습니다. 위치는 자동 저장되어 다음 실행 때도 같은 위치에 나타납니다. 도구 모음이 너무 크거나 작으면 설정창의 그리기 > 도구 모음 버튼 크기에서 조절합니다.

도구사용 방법활용 예
펜마우스를 누른 채 움직이면 자유 곡선이 그려집니다.문제 풀이 과정, 밑줄, 즉석 설명을 빠르게 남길 때 좋습니다.
형광펜반투명한 굵은 선으로 표시합니다.문서나 슬라이드의 중요한 문장을 가리지 않고 강조합니다.
직선시작점에서 누르고 끝점까지 드래그한 뒤 놓으면 직선이 완성됩니다.표, 그래프, 도식의 관계를 정확하게 표시합니다.
화살표드래그 방향을 따라 끝점에 화살표가 생깁니다.버튼 위치, 이동 방향, 설명 흐름을 가리킬 때 사용합니다.
사각형드래그한 영역을 감싸는 사각형을 그립니다.화면의 특정 영역, 입력칸, 표 범위를 강조합니다.
원드래그한 영역 안에 타원 또는 원을 그립니다.정답, 핵심 아이콘, 작은 버튼을 동그라미로 표시합니다.
도장도장 버튼을 눌러 별, 하트, 체크, X, 느낌표 중 하나를 고른 뒤 화면에 드래그하거나 클릭합니다.정답 표시, 주의 표시, 학생 발표 자료 피드백에 사용합니다.
지우개그린 내용을 지웁니다. 개체 지우개는 선이나 도형 전체를 지우고, 픽셀 지우개는 지나간 부분만 지웁니다.일부 설명만 지우거나, 잘못 그린 도형을 빠르게 제거합니다.

색상, 굵기, 선 모양 바꾸기

도구 모음의 색상, 굵기, 선 모양 버튼은 하나씩만 보이도록 작게 구성되어 있습니다. 버튼을 누르면 선택 창이 열리고 원하는 값을 고를 수 있습니다.

항목설명추천 사용
색상현재 그리기 색상을 바꿉니다. 펜 커서에도 현재 색상이 반영됩니다.빨강은 정답/오류, 파랑은 설명, 초록은 확인 표시처럼 역할을 나누면 보기 쉽습니다.
굵기선 두께를 조절합니다.문서 위 주석은 얇게, 발표 화면의 강조는 조금 두껍게 설정합니다.
선 모양실선, 점선 같은 선 스타일을 바꿉니다.확정된 내용은 실선, 참고나 예상 경로는 점선으로 구분하면 좋습니다.

고정 화면

명령 모드에서 K를 누르면 영역 선택 화면이 나타납니다. 원하는 영역을 드래그하면 그 부분이 테두리 없는 별도 창으로 열립니다. 창은 마우스 휠로 확대/축소하고, 화면에서 드래그하면 이동합니다. 창을 선택한 상태에서 Esc를 누르면 닫힙니다.

고정 화면 창에서 우클릭하면 확대, 축소, 원래 크기, 주석 모드, 입력 통과, 복사, 저장, 닫기 메뉴를 사용할 수 있습니다. 입력 통과를 켜면 창 아래의 프로그램을 클릭할 수 있지만, 이 상태에서는 창이 키 입력을 받지 못할 수 있습니다.

실시간 화면

명령 모드에서 G를 누른 뒤 영역을 드래그하면 해당 영역을 계속 갱신하는 실시간 화면 창이 열립니다. 문서의 작은 부분, 실습 프로그램의 결과 영역, 다른 모니터의 일부를 크게 보여줄 때 유용합니다.

실시간 화면도 휠 확대/축소, 드래그 이동, Esc 닫기, 우클릭 메뉴를 지원합니다. 여러 실시간 창을 모두 닫으려면 명령 모드에서 X를 누릅니다.

빠른 시작

exe 파일 기준으로 처음 실행하는 방법입니다.

처음기능과 단축키속성 설정문제 해결

1. 다운로드

메인 페이지의 실행 파일 다운로드 링크에서 ScreenAidStudio-0.1.0.0.exe 또는 배포용 압축 파일을 받습니다.

배포 주소는 메인 페이지의 다운로드 경로 입력 공간에 실제 주소를 넣어 사용하면 됩니다.

2. 실행

다운로드한 exe 파일을 더블클릭합니다. 실행 후 큰 창이 뜨지 않고 Windows 작업 표시줄 오른쪽의 트레이 영역에 ScreenAid Studio 아이콘이 표시됩니다.

3. 기본 조작

하고 싶은 일방법
설정 열기트레이 아이콘 더블클릭
트레이 메뉴 열기트레이 아이콘 우클릭
명령 모드 열기Ctrl + Alt + A
그리기 시작명령 모드에서 D
영역 캡처명령 모드에서 R
실시간 화면명령 모드에서 G

4. 종료

트레이 아이콘을 우클릭하고 종료를 선택합니다. 설정창을 닫아도 프로그램은 종료되지 않고 트레이에서 계속 실행됩니다.

빠른 시작

exe 배포판을 처음 실행하는 사용자를 위한 짧은 안내입니다.

처음기능과 단축키속성 설정문제 해결

1. 다운로드

메인 페이지의 실행 파일 다운로드 링크에서 ScreenAid Studio 배포 파일을 내려받습니다. 폴더 배포판을 받았다면 압축을 풀고 폴더 안의 ScreenAidStudio.exe를 실행합니다.

배포판은 exe 파일만 단독으로 옮기는 방식이 아니라, _internal, docs, resources, locales, config 폴더가 함께 있는 전체 폴더를 사용하는 방식입니다.

2. 실행

ScreenAidStudio.exe를 더블클릭합니다. 실행 후 큰 창이 뜨지 않고 Windows 작업 표시줄 오른쪽의 트레이 영역에 ScreenAid Studio 아이콘이 표시됩니다. 처음 실행하거나 설정창 표시 옵션이 켜져 있으면 설정창이 함께 열릴 수 있습니다.

3. 기본 조작

하고 싶은 일방법
설정 열기트레이 아이콘을 더블클릭합니다.
트레이 메뉴 열기트레이 아이콘을 우클릭합니다.
명령 모드 열기Ctrl + Alt + A를 누릅니다.
그리기 시작명령 모드에서 D를 누릅니다.
영역 캡처명령 모드에서 R을 누른 뒤 영역을 드래그합니다.
고정 화면 열기명령 모드에서 K를 누른 뒤 영역을 드래그합니다.
실시간 화면 열기명령 모드에서 G를 누른 뒤 영역을 드래그합니다.
클릭 표시 잠시 끄기/켜기Ctrl + Alt + E를 누릅니다.

4. 종료

트레이 아이콘을 우클릭하고 종료를 선택합니다. 설정창의 닫기 버튼을 눌러도 프로그램은 종료되지 않고 트레이에서 계속 실행됩니다.

배포 폴더 이동

다른 PC나 USB로 옮길 때는 ScreenAidStudio.exe만 복사하지 말고 ScreenAidStudio 폴더 전체를 복사하세요. 설정, 설명서, 아이콘, 클릭 표시 이미지, PySide6 실행 파일이 함께 있어야 정상 실행됩니다.

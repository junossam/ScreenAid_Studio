빠른 시작

처음 실행하는 사용자를 위한 짧은 안내입니다.

처음기능과 단축키속성 설정문제 해결

1. 최신 버전 다운로드

GitHub Releases 페이지에서 최신 ScreenAidStudio.zip 파일을 다운로드합니다.

최신 버전 다운로드

압축을 풀면 생기는 ScreenAidStudio 폴더 전체를 사용하세요. exe 파일만 따로 옮기면 아이콘, 언어, 도움말, 실행 라이브러리를 찾지 못할 수 있습니다.

2. 실행

압축을 푼 폴더 안의 ScreenAidStudio.exe를 더블클릭합니다. 기본적으로 별도 창 없이 트레이 영역에서 실행됩니다.

3. 기본 조작

하고 싶은 일방법
설정 열기트레이 아이콘을 더블클릭합니다.
트레이 메뉴 열기트레이 아이콘을 우클릭합니다.
명령 모드 열기Ctrl + Alt + A를 누릅니다.
그리기 시작명령 모드에서 D를 누릅니다.
영역 캡처명령 모드에서 R을 누른 뒤 영역을 드래그합니다.
고정 화면 열기명령 모드에서 K를 누른 뒤 영역을 드래그합니다.
실시간 영역 화면 열기명령 모드에서 G를 누른 뒤 영역을 드래그합니다.
현재 화면 확대명령 모드에서 F를 누릅니다.
실시간 전체 화면 확대명령 모드에서 J를 누릅니다.
창 또는 확대 종료고정 화면, 실시간 화면, 확대 상태에서 Esc를 누릅니다.

4. 종료

트레이 아이콘을 우클릭하고 종료를 선택합니다. 설정창의 닫기 버튼은 프로그램 종료가 아니라 설정창만 닫는 동작입니다.

다른 PC로 옮길 때

ScreenAidStudio.exe만 복사하지 말고 ScreenAidStudio 폴더 전체를 복사하세요. 실행에 필요한 파일, 도움말, 아이콘, 클릭 표시 이미지, 언어 파일이 함께 있어야 정상 실행됩니다.

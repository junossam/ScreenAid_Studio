무엇을 할 수 있나요?

M마우스 클릭 표시

왼쪽, 오른쪽, 양쪽 동시 클릭, 휠 클릭, 휠 드래그, 더블클릭을 화면에 표시합니다.

P화면 그리기

펜, 형광펜, 직선, 화살표, 사각형, 원, 도장, 지우개로 화면 위에 설명을 남깁니다.

C캡처와 고정 화면

원하는 영역을 캡처하고, 캡처한 이미지를 항상 위에 떠 있는 창으로 고정합니다.

L실시간 화면

선택한 영역을 작은 실시간 창으로 띄워 수업 자료나 시연 화면을 계속 보여줍니다.

저작권과 사용 범위

ScreenAid Studio는 MIT License 기준으로 제공되며, 저작권자는 JunoSsam입니다. 개인, 공공기관, 교육기관, 학교, 강의, 발표, 비영리 및 상업 환경에서 자유롭게 사용할 수 있습니다.

본 프로그램은 생성형 인공지능을 활용한 바이브 코딩 방식으로 개발되었습니다.

가장 먼저 기억할 것

동작방법
설정 열기트레이 아이콘을 더블클릭하거나, 우클릭 메뉴에서 설정을 선택합니다.
명령 모드 열기Ctrl + Alt + A를 누른 뒤 원하는 한 글자 명령을 누릅니다.
클릭 효과 잠시 끄기/켜기Ctrl + Alt + E를 누릅니다. 설정값은 바뀌지 않습니다.
전체 일시중지명령 모드에서 Space를 누르거나 트레이 메뉴의 전체 일시중지를 사용합니다.

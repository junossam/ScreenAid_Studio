주요 기능

M마우스 클릭 표시

왼쪽, 오른쪽, 양쪽, 휠 클릭, 휠 드래그, 더블클릭을 이미지로 표시합니다. 버튼을 누른 채 드래그하면 표시도 포인터를 따라 움직이고, 버튼을 놓으면 천천히 사라집니다.

D화면 그리기

펜, 형광펜, 직선, 사각형, 원, 화살표, 손그림 느낌 도장, 지우개를 사용할 수 있습니다. 색상, 굵기, 선 모양, 도구 모음 크기는 속성에서 조절합니다.

C캡처와 고정 화면

영역, 현재 모니터, 전체 가상 화면, 활성 창을 캡처합니다. 캡처 이미지는 테두리 없는 고정 창으로 띄우고 확대, 이동, 주석, 복사, 저장을 사용할 수 있습니다.

G실시간 영역 화면

선택한 영역을 계속 갱신되는 작은 창으로 보여줍니다. 기본 10FPS이며 휠 확대/축소, 드래그 이동, 우클릭 메뉴, Esc 닫기를 지원합니다.

F현재 화면 확대

현재 화면을 마우스 위치 기준으로 확대합니다. 확대 중 D로 확대 화면 위에 그릴 수 있고, 종료할 때 주석을 지우거나 원래 좌표에 남기도록 설정할 수 있습니다.

J실시간 화면 확대

마우스 커서를 따라 화면을 실시간으로 확대해서 보여줍니다. 마우스 휠로 배율을 1배~8배까지 조절하고, Esc 키를 누르면 바로 꺼집니다.

A명령 모드로 빠른 실행

Ctrl + Alt + A를 누르면 도움창이 뜨고, 이어서 한 글자만 누르면 그리기·캡처·고정 화면·실시간 화면·확대 같은 기능이 바로 실행됩니다. 마우스로 메뉴를 찾아다닐 필요가 없습니다.

KO한국어/영어 지원

기본 언어로 한국어와 영어를 제공합니다. 언어 파일을 추가하는 방식으로 다른 언어 확장도 고려한 구조입니다.

먼저 기억할 조작

동작방법
설정 열기트레이 아이콘을 더블클릭하거나, 트레이 아이콘 우클릭 메뉴에서 설정을 선택합니다.
명령 모드 열기Ctrl + Alt + A를 누른 뒤 원하는 한 글자 명령을 누릅니다.
그리기 모드명령 모드에서 D를 누릅니다. 다시 누르면 그리기 모드가 꺼집니다.
고정 화면명령 모드에서 K를 누른 뒤 영역을 드래그합니다.
실시간 영역 화면명령 모드에서 G를 누른 뒤 영역을 드래그합니다.
현재 화면 확대명령 모드에서 F를 누릅니다. 확대 중 D는 확대 화면 주석 모드입니다.
실시간 화면 확대명령 모드에서 J를 누릅니다. 마우스 휠로 배율 조절, Esc로 종료합니다.
클릭 효과 임시 표시/숨김Ctrl + Alt + E를 누릅니다. 속성값은 바뀌지 않습니다.

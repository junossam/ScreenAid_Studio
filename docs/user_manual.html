무엇을 할 수 있나요?

M마우스 클릭 표시

왼쪽 클릭, 오른쪽 클릭, 양쪽 동시 클릭, 휠 클릭, 휠 드래그, 더블클릭을 화면에 표시합니다. 수업 영상이나 원격 설명에서 사용자의 조작을 쉽게 따라오게 해줍니다.

P화면 그리기

펜, 형광펜, 직선, 화살표, 사각형, 원, 도장, 지우개로 화면 위에 설명을 남깁니다. 도구 모음은 작게 표시되며 원하는 위치로 옮길 수 있습니다.

C캡처와 고정 화면

원하는 영역을 캡처하고, 캡처한 이미지를 화면 위에 테두리 없는 창으로 고정할 수 있습니다. 고정 창은 확대, 축소, 이동, 주석을 지원합니다.

L실시간 화면

선택한 영역을 계속 갱신되는 작은 창으로 띄웁니다. 작은 실습 화면이나 다른 모니터의 일부를 크게 보여줄 때 유용합니다.

가장 먼저 기억할 것

동작방법
설정 열기트레이 아이콘을 더블클릭하거나, 우클릭 메뉴에서 설정을 선택합니다.
명령 모드 열기Ctrl + Alt + A를 누른 뒤 원하는 한 글자 명령을 누릅니다.
그리기 시작명령 모드에서 D를 누릅니다. 다시 D를 누르면 그리기 모드가 꺼집니다.
클릭 효과 잠시 끄기/켜기Ctrl + Alt + E를 누릅니다. 설정값은 바뀌지 않습니다.
고정 화면 열기명령 모드에서 K를 누르고 원하는 영역을 드래그합니다.
실시간 화면 열기명령 모드에서 G를 누르고 원하는 영역을 드래그합니다.

최신버전 파일 다운로드

무엇을 할 수 있나요?

M마우스 클릭 표시

왼쪽 클릭, 오른쪽 클릭, 양쪽 동시 클릭, 휠 클릭, 휠 드래그, 더블클릭을 화면에 이미지로 표시합니다.

P화면 그리기

펜, 형광펜, 직선, 화살표, 사각형, 원, 손그림 느낌의 별/하트 도장, 지우개로 화면 위에 설명을 남길 수 있습니다.

C캡처와 고정 화면

원하는 영역을 캡처하고, 캡처 이미지를 테두리 없는 창으로 고정합니다. 고정 창에서도 확대, 이동, 주석, 복사, 저장을 사용할 수 있습니다.

L실시간 화면

선택한 영역을 계속 갱신되는 작은 창으로 보여줍니다. 기본 10FPS이며 휠 확대/축소와 드래그 이동을 지원합니다.

F전체 화면 확대

명령 모드에서 F를 누르면 마우스 위치를 기준으로 화면이 부드럽게 확대됩니다. 마우스 휠로 추가 확대/축소하고 Esc로 닫습니다.

⚙자세한 속성 설정

언어, 오버레이, 클릭 표시, 알림, 그리기 도구, 캡처, 단축키, 명령 모드, 확대 기능을 속성 창에서 조절할 수 있습니다.

가장 먼저 기억할 것

동작방법
설정 열기트레이 아이콘을 더블클릭하거나, 트레이 아이콘 우클릭 메뉴에서 설정을 선택합니다.
명령 모드 열기Ctrl + Alt + A를 누른 뒤 원하는 한 글자 명령을 누릅니다.
그리기 모드명령 모드에서 D를 누릅니다. 다시 누르면 그리기 모드가 꺼집니다.
고정 화면명령 모드에서 K를 누른 뒤 영역을 드래그합니다.
실시간 화면명령 모드에서 G를 누른 뒤 영역을 드래그합니다.
전체 화면 확대명령 모드에서 F를 누릅니다. Esc로 종료합니다.
클릭 효과 임시 표시/숨김Ctrl + Alt + E를 누릅니다. 속성값은 바뀌지 않습니다.

속성 설정

설정창의 각 탭에서 바꿀 수 있는 항목을 설명합니다.

처음빠른 시작기능과 단축키문제 해결

저장 버튼

버튼동작
저장설정창을 닫지 않고 저장합니다. 바로 테스트해볼 때 사용합니다.
저장 후 닫기설정을 저장하고 설정창을 닫습니다.
취소마지막 저장 이후 바꾼 내용을 버리고 닫습니다.

일반

언어, 설정 저장 위치, Windows 시작 시 실행, 시작 시 설정창 숨김을 조절합니다. 기본 저장 방식은 휴대용 모드이며 실행 폴더의 user_data 아래에 설정이 저장됩니다.

오버레이

오버레이는 화면 위에 표시되는 투명한 보조 화면입니다. 마우스 클릭 표시, 그리기, 강조 표시가 이 오버레이 위에 나타납니다. 입력 통과를 켜면 오버레이가 떠 있어도 아래 프로그램을 계속 클릭할 수 있습니다.

클릭

클릭 표시 전체 사용 여부와 클릭 종류별 표시 여부를 설정합니다. 왼쪽 클릭, 오른쪽 클릭, 양쪽 동시 클릭, 휠 클릭 표시, 휠 드래그(돌리기) 표시, 더블클릭 표시를 각각 선택할 수 있습니다.

클릭 표시 이미지는 마우스를 누르면 나타나고, 누른 채 드래그하면 포인터를 따라 움직이며, 버튼을 놓으면 천천히 사라집니다.

캡처

기본 캡처 방식, 주석 포함, 클릭 효과 포함, 커서 포함, 클립보드 복사, 자동 저장, 저장 폴더와 파일명 규칙을 설정합니다. 마지막 캡처를 파일로 저장하는 명령은 Ctrl + Alt + A 후 I입니다.

알림

알림 전용 탭에서 전체 알림 표시 여부와 알림 종류별 표시 여부를 조절합니다.

항목설명
전체 알림 표시모든 알림을 한 번에 켜거나 끕니다.
캡처 완료/실패캡처 결과 알림을 표시할지 정합니다.
단축키 등록 실패다른 프로그램과 단축키가 충돌할 때 알려줍니다.
고정 화면/실시간 화면 실패창을 열 수 없을 때 알려줍니다.
그리기 입력 통과 전환현재 입력이 그리기에 쓰이는지, 아래 프로그램으로 통과되는지 알려줍니다.
일시중지/재개전체 기능 일시중지 상태 변화를 알려줍니다.
클릭 효과 임시 표시/숨김Ctrl + Alt + E 사용 시 상태를 알려줍니다.

그리기

기본 도구, 색상, 선 굵기, 선 모양, 투명도, 실행 취소 개수, 도구 모음 버튼 크기, 시작 시 입력 통과 여부, 그리기 중 클릭 표시 여부, 지우개 방식을 설정합니다.

고정 화면 / 실시간 / 확대

고정 화면은 기본 확대 배율, 최소/최대 확대, 입력 통과 기본값을 설정합니다. 실시간 영역 화면은 기본 FPS와 FPS 범위를 설정합니다.

확대 탭에서는 현재 화면 확대 사용 여부, 기본 확대 배율, 확대 종료 시 주석을 지울지 원래 화면에 남길지, 실시간 전체 화면 확대 배율을 설정합니다.

실시간 전체 화면 확대는 Windows Magnification API를 사용합니다. 확대된 위치에 정확히 입력을 연결하려면 Windows의 UIAccess 권한 환경이 맞아야 할 수 있습니다.

단축키와 명령 모드

전역 단축키는 명령 모드 열기와 클릭 효과 임시 표시/숨김을 바꿀 수 있습니다. 명령 모드 탭에서는 Ctrl + Alt + A를 누른 뒤 사용할 한 글자 명령을 바꿀 수 있습니다. 도움창이 불편하면 명령 모드 도움창 표시를 끄세요.

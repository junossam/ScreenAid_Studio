속성 설정

설정창의 각 탭에서 무엇을 바꾸는지 자세히 설명합니다.

처음빠른 시작기능과 단축키문제 해결

설정창 열기와 저장

트레이 아이콘을 더블클릭하면 설정창이 열립니다. 트레이 아이콘을 우클릭한 뒤 설정을 선택해도 열 수 있습니다.

버튼동작
저장창을 닫지 않고 설정을 저장하고 바로 적용합니다. 값을 바꿔 보면서 테스트할 때 사용합니다.
저장 후 닫기설정을 저장한 뒤 설정창을 닫습니다.
취소마지막 저장 이후 바꾼 내용을 적용하지 않고 닫습니다.

일반 탭

항목설명추천
언어프로그램 메뉴, 설정창, 툴팁에 사용할 언어를 선택합니다. 기본으로 한국어와 영어를 제공합니다.한국어 사용자는 한국어를 선택합니다. 언어를 바꾼 뒤에는 프로그램을 다시 실행하면 가장 확실합니다.
설정 저장 위치휴대용 모드 또는 AppData 모드 중 선택합니다.USB나 다른 PC로 폴더를 옮겨 쓸 계획이면 휴대용 모드를 권장합니다.
Windows 시작 시 실행Windows 로그인 후 자동으로 ScreenAid Studio를 실행합니다.수업용 PC에서 항상 사용할 경우 켭니다.
시작 시 설정창 숨기기프로그램 시작 시 설정창을 띄우지 않고 트레이에만 표시합니다.설정을 마친 뒤 평소 사용 단계에서는 켜두면 깔끔합니다.

오버레이 탭

오버레이는 클릭 표시와 그리기 내용을 화면 위에 보여주는 투명 창입니다. 평소에는 아래 프로그램 사용을 방해하지 않도록 입력 통과 방식으로 동작합니다.

항목설명
오버레이 사용화면 보조 표시 전체를 켜거나 끕니다. 끄면 클릭 표시와 그리기 표시가 보이지 않을 수 있습니다.
입력 통과오버레이 아래에 있는 PowerPoint, Chrome, Excel 같은 프로그램을 그대로 클릭할 수 있게 합니다.
투명도오버레이 표시의 전체적인 투명 정도를 조절합니다.

클릭 탭

마우스 클릭 표시를 어떤 방식으로 보여줄지 정합니다. 가장 위의 클릭 표시 사용은 전체 켜기/끄기입니다. 그 아래 마우스 클릭 표시 상자에서 클릭 종류별 표시 여부를 선택합니다.

항목설명추천
클릭 표시 사용클릭 표시 기능 전체를 켜거나 끕니다.수업이나 녹화 중에는 켜두고, 게임이나 정밀 작업 중에는 끌 수 있습니다.
왼쪽/오른쪽/양쪽 동시 클릭 표시각 버튼 클릭을 개별적으로 표시합니다.기본값처럼 모두 켜두면 설명이 가장 명확합니다.
휠 클릭 표시마우스 휠 버튼을 누르는 동작을 표시합니다.브라우저 새 탭 열기나 CAD류 프로그램 설명에 유용합니다.
휠 드래그(돌리기) 표시휠을 굴리는 방향을 화살표로 표시합니다.스크롤 방향을 보여줘야 하는 수업에서 켭니다.
더블클릭 표시왼쪽 버튼을 빠르게 두 번 누르면 별도 표시를 보여줍니다.파일 열기나 단어 선택 시연에 유용합니다.
이미지 사용기본 원형 효과 대신 마우스 모양 이미지를 표시합니다.일반 사용자에게는 이미지 방식이 더 직관적입니다.
이미지 크기클릭 표시 이미지의 크기를 조절합니다.36 전후가 기본입니다. 빔프로젝터에서는 조금 키워도 좋습니다.
이미지 간격마우스 포인터와 클릭 표시 이미지 사이의 거리입니다.표시가 포인터와 겹치면 값을 키우고, 너무 멀면 줄입니다.
유지 시간 / 사라짐 시간클릭 표시가 얼마나 오래 보이고 얼마나 부드럽게 사라질지 정합니다.빠른 설명은 짧게, 녹화 영상은 조금 길게 설정합니다.
클릭 색상이미지를 사용하지 않을 때 표시되는 원형 효과 색상입니다.배경과 잘 구분되는 색을 선택합니다.

Ctrl + Alt + E는 클릭 효과를 임시로 숨기거나 다시 보이는 전역 단축키입니다. 이 단축키를 눌러도 설정창의 체크 상태는 바뀌지 않습니다.

캡처 탭

항목설명
클릭 효과 포함캡처 이미지에 클릭 표시까지 포함할지 정합니다.
커서 포함캡처할 때 마우스 커서를 함께 넣을지 정합니다.
클립보드 복사캡처 후 이미지를 클립보드에 복사합니다. 문서나 메신저에 바로 붙여넣을 때 편합니다.
자동 저장캡처 이미지를 파일로 자동 저장합니다.
저장 형식 / 파일명PNG 같은 저장 형식과 파일 이름 규칙을 정합니다.

그리기 탭

그리기 모드에서 처음 선택될 도구와 기본 모양을 정합니다. 도구 모음에서 바꾸는 값은 즉시 사용하는 값이고, 설정창의 값은 프로그램을 시작하거나 초기화할 때 기준이 되는 값입니다.

항목설명추천
그리기 사용그리기 기능 전체 사용 여부입니다.화면 주석을 쓰지 않는 PC에서는 끌 수 있습니다.
기본 도구그리기 모드를 켰을 때 처음 선택되는 도구입니다.대부분의 수업에서는 펜 또는 형광펜이 편합니다.
그리기 색상기본 선 색상입니다.밝은 화면에서는 빨강/파랑, 어두운 화면에서는 노랑/하늘색이 잘 보입니다.
선 굵기펜, 직선, 도형의 기본 굵기입니다.문서 설명은 3~5, 발표 화면은 5~8 정도가 보기 좋습니다.
선 모양실선, 점선 같은 기본 선 스타일입니다.기본은 실선이 가장 명확합니다.
그리기 불투명도그린 선이 얼마나 진하게 보일지 정합니다.펜은 높게, 형광펜 느낌은 낮게 설정합니다.
도구 모음 버튼 크기그리기 도구 모음 아이콘 크기입니다.화면을 가리지 않게 28 전후를 권장합니다. 터치 화면이면 조금 키웁니다.
그리기 중 클릭 표시그리기 모드에서도 마우스 클릭 효과를 보일지 정합니다.선 그리기에 집중하려면 끄고, 클릭 설명까지 보여줘야 하면 켭니다.

지우개 설정

항목설명언제 쓰나요?
개체 지우개클릭한 선, 도형, 도장 전체를 지웁니다.잘못 그린 화살표나 원 하나를 통째로 지울 때 빠릅니다.
픽셀 지우개지우개가 지나간 경로만 지웁니다.긴 밑줄 일부, 펜 글씨 일부처럼 필요한 부분만 지울 때 사용합니다.
지우개 크기픽셀 지우개 또는 지우개 판정 범위를 정합니다.작은 글씨는 작게, 큰 발표 화면 주석은 크게 설정합니다.

고정 화면 탭

항목설명
기본 확대 배율고정 화면 창이 처음 열릴 때의 확대 비율입니다.
최소/최대 확대마우스 휠로 줄이거나 키울 수 있는 범위를 제한합니다.
입력 통과 기본값고정 화면 창 아래의 프로그램을 클릭할 수 있게 할지 정합니다.

실시간 탭

항목설명추천
기본 FPS실시간 화면이 1초에 몇 번 갱신될지 정합니다.기본 10FPS 정도면 수업용으로 충분합니다.
최소/최대 FPS우클릭 메뉴 등에서 조절할 수 있는 FPS 범위입니다.성능이 느리면 FPS를 낮추고 영역을 작게 선택합니다.

단축키 탭

전역 단축키는 다른 프로그램을 사용 중이어도 동작하는 단축키입니다. 기본값은 명령 모드 열기 Ctrl + Alt + A, 클릭 효과 임시 표시/숨김 Ctrl + Alt + E입니다.

다른 프로그램과 충돌하면 단축키 등록 실패 알림이 뜰 수 있습니다. 이 경우 Ctrl + Alt + 다른 알파벳처럼 덜 쓰는 조합으로 바꿉니다.

명령 모드 탭

명령 모드 안에서 누르는 한 글자 키를 바꿀 수 있습니다. 예를 들어 그리기 모드 토글을 D 대신 P로 바꾸는 식입니다. 단, 같은 키를 여러 명령에 중복으로 넣으면 원하는 명령이 실행되지 않을 수 있으니 서로 다른 키를 사용하세요.

항목설명
대기 시간명령 모드가 열린 뒤 아무 키도 누르지 않았을 때 자동으로 닫히는 시간입니다.
명령별 키그리기, 캡처, 창, 설정 등 각 명령에 사용할 한 글자 키입니다.

영역 선택 탭

영역 캡처, 고정 화면, 실시간 화면을 시작할 때 나타나는 드래그 선택 화면의 모양을 조절합니다. 선택 테두리 색, 테두리 굵기, 어둡게 처리되는 배경, 최소 영역 크기 등을 바꿀 수 있습니다.

설정창 열기와 저장

트레이 아이콘을 더블클릭하면 설정창이 열립니다. 저장은 창을 닫지 않고 바로 적용하며, 저장 후 닫기는 저장한 뒤 창을 닫습니다.

언어

한국어와 영어를 기본 지원합니다. 설정창에서 언어를 바꾼 뒤 프로그램을 다시 실행하면 메뉴와 툴팁에 적용됩니다.

설정 저장 위치

기본값은 휴대용 모드입니다. exe 주변의 사용자 데이터 폴더에 설정이 저장됩니다. AppData 모드를 선택하면 Windows 사용자 AppData 폴더에 저장됩니다.

지우개 모드

개체 지우개는 클릭한 선이나 도형 전체를 지웁니다. 픽셀 지우개는 지우개가 지나간 경로만 지웁니다.
